# LeadFilter Pro - Excel & CSV Position Filter React App

A modern, professional React application designed to filter contact and connection lists (like LinkedIn exports) by **Company Position** using radio buttons, with real-time search and multi-format export capabilities.

## Features
- 📁 **Universal File Upload**: Supports both `.csv` and Excel spreadsheets (`.xlsx`, `.xls`).
- 🔘 **Radio Button Position Filtering**: Automatically extracts all unique company positions and presents them as interactive radio buttons with count indicators.
- 🔍 **Position Search & Sorting**: Built-in search input and sort toggle (by count or alphabetical) to easily locate specific roles among dozens or hundreds of positions.
- 📋 **Professional Data Table**:
  - Displays **First Name**, **Last Name**, **Position**, **Company**, **Email Address**, **URL**, and **Connected On**.
  - One-click copy for emails and clickable links for LinkedIn/URL profiles.
  - Table search filter to quickly find specific individuals or companies within filtered positions.
  - Configurable pagination (10, 25, 50, 100 rows per page).
- 💾 **Export & Download**: Download filtered datasets with 1-click in both **CSV** and **Excel (.xlsx)** formats.
- ⚡ **Demo Dataset**: Included sample dataset to preview immediately without uploading a file.

## Running the Application
The Vite development server is running at:
```bash
http://localhost:3000/
```
To restart or build:
```bash
# Start dev server
npm run dev

# Build production bundle
npm run build
```
